## 정리

- 호스트 메트릭 수집(Metricbeat → ES → Kibana)은 **구현·확인됨**.
- 인덱스 기반 Shadow API 분류(enrich)는 팀 실제 로그 108만 줄로 재현 · 수정 완료 — Shadow 성공 응답은 `GET /api/v1/users/{id}`(31,715) · `GET /api/v1/diagnostics/ping`(2).
- 노션 캡처 일부에 Elastic Agent 설치 키(install-key · ingest-key)가 보인다. 실습 환경은 없어졌지만 노션 페이지를 공개할 때는 가린다.
